TERMS IN LEXICAL ANALYSIS
Token:
A pair consisting of token name and an optional attribute value.
Remember the form <token-name, attribute-value>
Pattern:
An informal description of a form that lexemes of a token may take. For e.g. if
token is a keyword , then pattern is just the sequence of characters that form the
keyword.
Lexeme:
It is an actual stream of characters (in the source program) that matches the pattern
and is identified by the lexical analyzer as an instance of that token.

SENTINELS
▪Each time we move forward, we must check that we have not moved off one of the
buffers. Because if we do, we must reload the other buffer.
▪Thus for each character read, we make two tests: one for the end of buffer and one
to determine what character is read.
▪The buffer end test can be combined with the test for the current character if we
extend each buffer to hold a sentinel character at the end.
▪Sentinel is the special character that cannot be a part of the source program and
the natural choice is eof.

 is a regular expression, and L() is {}, that is, the language whose sole member

REGULAR DEFINITIONS
Regular definitions allow names to be given
to certain regular expressions. These names
can then be used in subsequent expressions
as if they were symbols.
If ∑ is an alphabet of basic symbols, then a
regular definition is a sequence of definitions
of the form:
d1→r1
d2 → r2
…
dn → rn
where:
1. Each  is a new symbol, not in ∑ and
not the same as any other of the d’s
2. Each  is a regular expression over the
alphabet ∑∪{1, 2, …, −1},

TRANSITION
DIAGRAMS
Consists of:
1. A collection of nodes or circles, called states.

Each state represents a condition that could occur during the process of scanning
the input looking for a lexeme that matches one of several patterns
2. Edges are directed from one state of the transition diagram
to another.

Each edge is labeled by a symbol or set of symbols.
CPT316 PROGRAMMING LANGUAGE IMPLEMENTATION AND PARADIGMS
Diagram representation / semantic relationships:
Transition diagrams represent lexical recognition as directed states and input-labeled
transitions. Acceptance is indicated by designated final states.
